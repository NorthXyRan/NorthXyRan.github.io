# Fengyan (Daniel) Lin — Personal Homepage

Edit `contents/*.md` for page content. Add one file per paper in `contents/publications/`, using [publication.md](templates/publication.md) as the template.

## Quick start

Double-click [preview.command](preview.command) to open the local preview. The first launch requires Python 3.10+ and an internet connection to install dependencies. Saving content automatically rebuilds the site and reloads the browser.

For GitHub Pages, select **Settings → Pages → Source → GitHub Actions**. The workflow builds and deploys on pushes to `main`. Generated `index.html` and `data/*.json` files are created during preview or deployment and are not committed.
